# Gesture

基于 OpenCV 和 MediaPipe 的实时手势绘图实验。项目可以通过摄像头追踪手部关键点，并使用拇指与食指捏合在白板或实时视频上绘制轨迹。

## 功能

- 实时手部关键点检测
- 拇指与食指捏合绘制
- 默认使用独立白板画布
- AR 模式下在摄像头视频上叠加绘制
- 保留多条独立轨迹
- 握拳抓取、移动和缩放轨迹
- 将轨迹拖至画面角落后松手删除
- 两只手从左右向中央击掌清屏
- 单手左右挥动开启或关闭手势识别
- 左上角实时显示检测到的手数和可触发操作
- 可调的全局移动放大倍数，以较小手部动作覆盖更大画布范围

## 环境要求

- Python 3.11 或更高版本
- 可用的摄像头
- macOS、Windows 或 Linux

安装依赖：

```bash
python -m pip install -r requirements.txt
```

请勿同时安装 `opencv-python` 和 `opencv-contrib-python`，因为两者提供同一个 `cv2` 模块。本项目使用 MediaPipe 依赖的 `opencv-contrib-python`。

项目使用 MediaPipe Hand Landmarker 模型，默认路径为：

```text
models/hand_landmarker.task
```

如果模型文件不存在，可以下载官方模型：

```bash
mkdir -p models
curl -fL \
  -o models/hand_landmarker.task \
  https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
```

## 运行手部关键点检测

```bash
python main.py
```

该脚本在摄像头画面上绘制手部骨架、左右手信息和检测置信度。

如果默认摄像头不可用，可以指定其他摄像头编号：

```bash
python main.py --camera 1
```

## 运行手势画板

### 白板模式（默认）

```bash
python pinch_tracker.py
```

摄像头在后台用于识别手势，窗口只显示白色画布和绘制结果。

程序启动后，手势识别系统默认关闭。将一只手从画面左侧挥到右侧，即可开启绘图手势识别。

### AR 模式

```bash
python pinch_tracker.py --mode AR
```

AR 模式会将中心点、轨迹和操作提示叠加在实时摄像头画面上。模式名称不区分大小写。

## 手势操作

| 操作 | 手势 |
| --- | --- |
| 开启识别系统 | 一只手从画面左侧挥到右侧 |
| 关闭识别系统 | 一只手从画面右侧挥到左侧 |
| 移动指针 | 移动拇指与食指，指针位于两指指尖中心 |
| 开始绘制 | 捏合拇指与食指，中心点由红色变为绿色 |
| 结束绘制 | 分开拇指与食指 |
| 抓取轨迹 | 将手掌移至轨迹附近并握拳 |
| 移动轨迹 | 保持握拳并移动手掌 |
| 缩放轨迹 | 保持握拳并让手靠近或远离摄像头 |
| 删除轨迹 | 将抓取的轨迹移至任一角落，然后张开手 |
| 清空画布 | 两手分别从画面左右向中央移动并击掌 |

抓取并放置轨迹后有 1.5 秒绘制冷却时间，避免松手动作立即触发新轨迹。删除轨迹后也有 1.5 秒操作冷却时间。抓取轨迹时，手掌中心需要位于轨迹约 80 像素范围内。

识别系统关闭后，已有轨迹会继续保留，但捏合绘制、抓取、删除和击掌清屏均会暂停。系统仍会在后台检测从左向右的单手挥动，以便重新开启。

画布左上角会实时显示 `Hands: 0`、`Hands: 1` 或 `Hands: 2`。单手状态会提示系统开关方向，双手状态会提示击掌清屏是否可用。

快速挥手过程中允许最多约 300ms 的连续漏检。短暂未识别到手时会保留挥动起点；持续丢失超过该时间或检测到双手时，才会重置单手挥动状态。

击掌清屏同样允许最多约 300ms 的双手漏检。在两手快速靠近期间，即使短暂只检测到一只手或没有检测到手，也会保留击掌准备状态和上一组双手位置；超时后才会重置。两手在画面中央接触重叠、被模型暂时识别成一只手时，系统也会结合此前的向内运动和双手间距推断击掌完成。

## 调整捏合灵敏度

捏合比例的计算方式为：

```text
两指指尖像素距离 / 画面短边像素数
```

默认开始阈值为 `0.04`，分离阈值为 `0.06`：

```bash
python pinch_tracker.py \
  --pinch-threshold 0.04 \
  --release-threshold 0.06
```

增大阈值会让捏合更容易触发。分离阈值必须大于开始阈值，以避免临界距离造成状态抖动。

## 调整移动放大倍数

所有位置坐标默认以画面中心为基准放大 `2.0` 倍，使较小的手部动作可以覆盖更大的画布范围。该增益作用于绘图、轨迹移动、角落删除、系统开关和击掌手势，不改变捏合距离与握拳形状判断。

```bash
python pinch_tracker.py --movement-gain 2.5
```

`1.0` 表示手部位置与画布位置一一对应；数值越大，移动灵敏度越高。超出画布范围的坐标会被限制在画布边缘。

## 常用参数

```text
--camera CAMERA                 摄像头编号
--mode {WHITEBOARD,AR}          显示模式
--model MODEL                   MediaPipe 模型路径
--pinch-threshold VALUE         开始捏合阈值
--release-threshold VALUE       结束捏合阈值
--movement-gain VALUE           手部移动映射到画布的放大倍数
```

查看全部参数：

```bash
python pinch_tracker.py --help
```

## 退出

在显示窗口中按 `Q` 或 `Esc`。

## 数据保存

代码中保留了将轨迹写入 CSV 的实现，但相关调用目前已注释，运行时不会创建 CSV 文件。CSV 功能可以在 `pinch_tracker.py` 中重新启用。

## macOS 摄像头权限

首次运行时，macOS 可能会请求摄像头权限。如果无法打开摄像头，请在“系统设置 → 隐私与安全性 → 摄像头”中允许终端或所使用的 IDE 访问摄像头。

程序在 macOS 上会优先使用 AVFoundation 摄像头后端。摄像头由独立后台线程持续读取，识别计算或界面短暂停顿不会阻塞取帧。断流时程序会在后台持续重新打开摄像头，而不会因固定次数的读取失败直接退出。如果长时间无法恢复，请关闭可能占用摄像头的 FaceTime、Photo Booth、浏览器会议页面等程序，或尝试：

```bash
python pinch_tracker.py --camera 1
```

MediaPipe 0.10.35 可能输出包含 `portable_clearcut_uploader` 的日志。该日志来自 MediaPipe 包内的遥测上传组件，并不是摄像头读取失败的原因。
